# Lunagram для iOS

> Что и в каком порядке собиралось, с неудачами, — в [журнале испытаний](JOURNAL.md).

Форк настоящего Telegram для iOS. Вид и все возможности родные, наши
доработки накладываются заплатками поверх.

## Почему так, а не копией исходников

Исходники Telegram для iOS весят полтора гигабайта. Держать их у себя —
значит каждый раз при обновлении Telegram разбирать конфликты слияния
руками во всём дереве. Поэтому здесь лежат только **наши изменения**, а
исходники скачиваются во время сборки на нужной версии.

Обновиться на новую версию Telegram — поменять `TELEGRAM_TAG` в
`.github/workflows/build.yml` и, если заплатки не легли,
переписать их.

## Что нужно один раз

1. **Ключи Telegram API.** Получить на <https://my.telegram.org> →
   API development tools. Положить в репозиторий:
   Settings → Secrets and variables → Actions → New repository secret,
   имена `LG_API_ID` и `LG_API_HASH`.

2. **Открытый репозиторий.** Сборка идёт на macOS, а такие машины у
   GitHub платные: для закрытого репозитория минуты Mac считаются в
   десять раз. Бесплатных 2000 минут в месяц хватает примерно на одну
   сборку. Для открытого репозитория Actions бесплатны без ограничений.
   Исходники Telegram и так открыты (GPL), ключи лежат в секретах и в
   код не попадают.

## Как собрать

Actions → «Собрать Lunagram» → Run workflow. Полная сборка с нуля идёт
два-три часа. Готовый файл появится в артефактах под именем
`Lunagram-ipa`.

## Как поставить на айфон

Собранный файл не подписан ключом Apple — подпись ставится уже на
устройстве.

**iOS 17 и новее** — SideStore (<https://sidestore.io>). Один раз нужен
компьютер, чтобы создать pairing-файл, дальше подпись продлевается сама
в фоне.

**iOS 16.6.1 и ниже** — если прошивка поддерживается, лучше TrollStore:
подпись ставится навсегда. Проверить: <https://ios.cfw.guide/installing-trollstore/>

Внутри файла остаётся телеграмовский идентификатор `ph.telegra.Telegraph` —
так задумано: под него сделаны профили подписи в исходниках Telegram, а
программа установки подставляет свой. Если официальный Telegram тоже
стоит на телефоне, установщик предложит поменять идентификатор, чтобы
приложения не затирали друг друга — соглашайся.

## Заплатки

Лежат в `patches/`, накладываются по алфавиту через `git apply`.
Каждая — обычный diff относительно дерева Telegram.

Сейчас лежат:

- `0001-lunagram-settings-and-particles.patch` — модуль `Lunagram` со
  своими настройками, раздел «Lunagram» в настройках Telegram и первая
  функция: частицы поверх фона переписки.
- `0002-ghost-mode.patch` — Ghost: не отмечать прочитанным (вместе с
  прослушиванием голосовых), не показывать «печатает…», не выходить в
  сеть, не отмечать истории. Каждое — отдельным выключателем.
- `0003-live-wallpaper.patch` — живые обои: видео из галереи вместо обоев
  переписки, без звука, с затемнением на выбор.
- `0004-moon-icon.patch` — значок: луна с ПК на ночном фиолетовом вместо
  самолётика.
- `0005-ghost-own-module.patch` — выключатели Ghost в отдельном маленьком
  модуле: новые функции больше не пересобирают сетевую часть Telegram.
- `0006-profile-banner.patch` — баннер профиля: фото или видео в шапке
  своего профиля, с затемнением.
- `0007-dialog-cards.patch` — плитки в списке переписок: фон строки —
  размытая аватарка.
- `0008-particle-kinds.patch` — частицы как на ПК: снег, сакура, матрица,
  дождь, листья; густота и скорость.
- `0009-hide-own-phone.patch` — скрыть свой номер для скриншотов.
- `0010-device-name.patch` — своё имя устройства в списке сеансов.
- `0011-avatar-frame.patch` — девять рамок вокруг аватарки.
- `0012-banner-presets.patch` — десять нарисованных баннеров.
- `0013-keep-deleted-messages.patch` — удалённые собеседником сообщения
  остаются, с метлой возле времени.
- `0014-edit-history.patch` — история изменений: прежние версии сообщения
  в его меню.

Имя приложения меняется уже в готовом файле — эта правка не трогает
сборочный граф Bazel и переживает обновление Telegram.

Сборка запускается сама, как только меняются заплатки или сборочный файл.

## Лицензия

Telegram для iOS распространяется под GPLv2. Заплатки в `patches/` —
производная работа от него, поэтому лежат открыто и под той же
лицензией.
